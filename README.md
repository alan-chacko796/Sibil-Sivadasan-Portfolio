## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/alan-chacko796/Sibil-Sivadasan-Portfolio.git
cd Sibil-Sivadasan-Portfolio

# Install dependencies
npm install

# Generate the official ATS-compliant Resume PDF
npm run generate-pdf

# Start development server
npm run dev

# Build for production
npm run build
```
